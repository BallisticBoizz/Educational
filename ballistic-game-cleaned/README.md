# Ballistic Game

This is a simple web-based game called **Ballistic**.

## Project Structure

- `html/game.html` - Main HTML file
- `css/game.css` - Styling for the game
- `javascript/` - JavaScript logic and scripts
- `asset/` - Icons and images used in the game

## Running Locally

1. Clone the repository.
2. Open `html/game.html` in a browser.
